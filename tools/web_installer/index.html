USB로 설치 (첫 설치 · 복구)

  1. 데스크톱 크롬 또는 엣지로 이 페이지를 엽니다.
  2. TONEX One에서 USB 케이블을 빼고, 보드의 Boot 버튼을 누른 채 컴퓨터에 USB-C로 연결한 뒤 버튼을 뗍니다.
  3. 아래 버튼을 누르고 포트(보통 USB JTAG/serial debug unit)를 고른 뒤 Install Tonex Controller fork → Next → Install 순서로 누릅니다.
  4. 끝나면 USB를 빼고 9V 전원(1A 이상)으로 켭니다. 컴퓨터 USB 전원만으로는 화면이 깨집니다.

중간에 나오는 Erase device를 체크하면 플래시 전체를 지웁니다. 보드 설정(Bluetooth·Wi-Fi·프리셋 순서·부스트·초콜릿 매핑)이 모두 기본값으로 돌아갑니다. 설정을 유지하려면 체크하지 마세요. 업스트림 펌웨어에서 처음 넘어올 때도 체크하지 않아도 됩니다.

이 브라우저는 USB 설치(Web Serial)를 지원하지 않습니다. 데스크톱 크롬 또는 엣지로 여세요.

HTTPS 주소나 localhost에서만 설치할 수 있습니다.

Wi-Fi로 업데이트

포크 펌웨어가 이미 설치된 보드는 USB 없이 앱 이미지 하나만 올리면 됩니다.

  1. 아래 파일을 받습니다.
  2. 폰을 보드 Wi-Fi(TonexConfig, 보드를 켠 뒤 1분 안에)에 붙이고 http://192.168.4.1에 접속합니다. Station 모드라면 보드 화면에 뜬 IP로 접속합니다.
  3. Config > Firmware에서 받은 파일을 올립니다. 100%가 되면 보드가 재부팅합니다.
TonexController.bin 받기

스킨 이미지가 바뀐 업스트림 버전을 받았거나 Wi-Fi 업데이트가 안 되면 위의 USB 설치를 씁니다. 자세한 내용은 펌웨어 업데이트 문서.

업스트림 설치 페이지(builty.github.io/TonexOneController)는 파티션 표가 달라 이 펌웨어를 설치하지 못합니다. 그쪽으로 설치하면 업스트림 펌웨어로 돌아갑니다.
